# Gianna Gioia — UX Research Portfolio

A researcher and designer who investigates the factors that shape human behavior and decision-making, then translates those insights into products, services, and systems that help people act with confidence.

## Case studies

- **Field service ethnography**: contextual inquiry and systems thinking (in progress)
- **Enterprise usability testing**: moderated usability testing of software for small-business owners (in progress)
- **Fuel Em**: conversational UX and AI-assisted decision support
- **Let’s Rally**: translating research into product strategy ([live prototype](https://lets-rally.vercel.app/))

## Files

- `index.html`: the complete site in one self-contained file (images embedded). Open it in a browser, or serve it with GitHub Pages.
- `resume.pdf`: résumé linked from the site.
- `prototype/fuelem/`: the interactive Fuel Em prototype, linked from the Fuel Em case study.
- `src/`: the source sections the page is built from (`shell.html` holds the layout, styles and scripts; each project has its own file).
